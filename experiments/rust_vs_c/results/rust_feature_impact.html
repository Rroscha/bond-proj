How The Matching Works

What is a Basic Block?

A basic block (BB) is a straight-line sequence of machine instructions with one entry and one exit. Think of it as one "step" of execution — the CPU runs every instruction in a block before jumping to the next.

Hungarian Algorithm Matching

We use the Hungarian algorithm to find the optimal 1-to-1 pairing between O0 blocks and O2 blocks. Each pair gets a similarity score (0.0 – 1.0) based on:

Opcodes
Same instruction types? (mov, cmp, jmp...)
Constants
Same numeric values? (0x100, 42...)
Structure
Same callee functions? Same # instructions?
Size
Similar instruction count?

fn bc_06(data: &mut [u64], initial_gap: usize) -> u64 {
    let n = data.len();
    let mut swaps = 0u64;
    let mut gap = initial_gap;
    while gap > 0 {
        for i in gap..n {
            let temp = data[i];        // bounds check!
            let mut j = i;
            while j >= gap && data[j - gap] > temp {
                data[j] = data[j - gap];  // 2 checks
                j -= gap; swaps += 1;
            }
            data[j] = temp;            // bounds check!
        }
        gap /= 2;
    }
    swaps
}

Key Findings

Features That HELP Matching

1. Bounds checks from data[i]
Each array access → cmp + conditional_jump block, nearly identical at O0 and O2. Scores 0.85–1.00 consistently. The single most valuable anchor.
2. The ? operator
Generates explicit branch blocks that check discriminant tags. Structurally similar to bounds checks. Scores 0.85–0.90.
3. Explicit indexing in ownership code
a[i] and b[j] on owned Vecs get the same bounds-check benefit. Drop glue adds moderate signal (0.6–0.9).

Features That HURT Matching

1. Iterator chains
.iter().filter().map().collect() — each adapter is a call at O0, fully inlined at O2. O0 and O2 blocks share almost nothing. Worst offender.
2. match on recursive enums
Compiles to jump tables with indirect jmp rax. CFGFast cannot follow → only 1 visible block. Worst category (delta −0.130).
3. Option method chains
.map().filter().unwrap_or() — same inlining problem as iterators. Use ? instead for better matching.

The Core Pattern

Structural patterns (comparisons, branches) survive optimization.
Function calls to generic library code do not.
